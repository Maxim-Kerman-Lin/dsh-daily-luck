# 今日好运来临（dsh-daily-luck）

DSH Web UI 插件：写入生日，用**真实星历**算出今日基础运势（不直接展示）；再从洗好的 22 张大阿尔卡纳里亲手抽一张（含正/逆位），两层叠加后给出「事业 / 感情 / 财运 / 身心 / 交际」**五维评分**、综合分与今日评语。

## 安装

在 dsh 里执行：

```sh
dsh plugin add github:Maxim-Kerman-Lin/dsh-daily-luck
```

装好后刷新页面，侧栏底部会出现 **✦ 今日好运**。

## 安装后在哪里

- 侧栏底部（设置旁边）多一个 **✦ 今日好运** 徽标入口（塔罗牌 + 星芒的紫金渐变图标）；
- 点开是全屏浮层：生日表单 → 洗牌 → 22 张牌背 → 翻开结果。

## 计算口径（全部在浏览器本地，确定性）

1. **基础运势（隐藏层）**
   - 太阳星座：按生日月/日落在黄道十二宫；
   - 出生太阳黄经：有出生年份时用星历真算（无年份用星座中点）；
   - 今日星象：太阳、月亮、水星、金星、火星、木星、土星的**地心黄经**与所在星座；
   - 相位：行运行星与本人太阳的合/六分/四分/三分/对分（含容许度与入相权重）；
   - 逆行：用黄经差判定（如 2024-04、2025-03、2026-03 的水逆会自动识别）；
   - 月相：由太阳—月亮黄经差算八相。
   这一层只参与评分，**不出现在界面上**。
2. **抽牌**
   - 22 张全量、Fisher–Yates 洗牌，正逆各 50%；
   - 用户自己点牌背，程序不再改牌；
   - 当日第一抽记入 localStorage，重新打开直接看结果。
3. **合成（五维）**
   - 每张牌在五维上有落点权重（以 0.58 为中性轴：强项抬高、弱项压低）；
   - 再叠加「牌势」：吉牌整体抬、重牌整体压；
   - 逆位统一「削峰 + 下压」，保证同一张牌逆位不高于正位；
   - 牌元素与太阳元素做同元素 / 相生 / 相冲修正；
   - **综合分 = 基础分打底 + 牌面加减**：基础分由五维基础盘均值映射（40 起），牌面按五维增量加权（主落点 1.4、最短板 1.15、其余 1.0）——好牌加、坏牌减（负向扣得更实），原始分再线性映射到 **40–100**；
   - 档位：大吉 ≥86 / 顺遂 ≥74 / 平稳 ≥62 / 留意 ≥50 / 蓄力 <50，并在分数旁给出「今日大吉，运势不错」这类一句话评语；
   - 结果页开头按用户填写的称呼打招呼（未填则「Hi，今天好」）。

## 结果页

- 开头「Hi，你的称呼，今天好」；
- 牌面 + 分数 + 星级 + 一句话评语（今日大吉 / 顺遂 / 平稳 / 留意 / 蓄力）；
- **提问答案**：抽牌前写过问题，先按问题类型（该不该 / 怎么 / 什么时候 / 为什么）和关键词（方案、面试、表白、投资…）给一句直接结论，再结合牌义与今日底盘解释（内部牌面为主、基础为辅，界面不显示占比），随后给 3 条具体做法（含牌面提示）和一句判断标准；没写问题则只显示「心想事成」；
- 五维评分条、牌义与生活化解读、「今天可以这样用这张牌」、今日评语与两条建议；
- 操作按钮：「重新抽卡」（紫金渐变）与「修改生日」（淡紫渐变），明确标注用途。

## 星历精度

用 JPL 近似轨道根数（1800–2050）+ 简化 ELP 月亮公式，属于低精度星历：太阳/行星约 0.1°–1°，月亮约 0.1°–0.3°，对相位判定足够；不是专业占星软件级精度。

## 隐私

生日、称呼、抽牌结果只写入**这台设备的 localStorage**，不向 Host 或任何服务发送；插件 Host 半为空壳（`index.js` 只有 `apply() {}`）。

## 娱乐边界

评分是「简化判定 + 可视化」，属于娱乐向自我观照，不构成医疗、投资、法律或婚姻建议；牌义为通行正逆位解读的白话转写。

## 文件

| 文件 | 作用 |
| --- | --- |
| `package.json` | bundle 清单 + `dsh.client`（platform: web） |
| `cordis.patch.yml` | 插入空壳 Host 行 |
| `index.js` | Host 半 `apply() {}` |
| `client.js` | 全部逻辑与 UI（React，无外部依赖） |
| `locale/zh.json`、`locale/en.json` | 插件管理页的标题与描述 |
| `icon.svg` | 插件图标 |
| `selftest.cjs` | 引擎自测（星座边界/星历/水逆/相位/评分/正逆单调） |
| `smoke3.cjs` | 视图形冒烟（表单/抽牌/结果） |

## 自测

```powershell
node selftest.cjs   # 引擎：星座、太阳黄经、满月、水逆、相位、五维评分
node smoke3.cjs     # 视图：表单 / 22 张牌背 / 结果页五维与提示
```
